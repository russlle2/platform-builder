# Google Search Console setup for dailyclarity.org

Follow these steps to verify domain ownership and submit the sitemap.

## 1. Create the property

1. Go to [Google Search Console](https://search.google.com/search-console).
2. Click **Add property**.
3. Choose **Domain** (not URL prefix).
4. Enter `dailyclarity.org` and continue.

## 2. Meta tag verification (app deploy)

1. On the verification screen, select the **HTML tag** method.
2. Google shows a meta tag like:
   ```html
   <meta name="google-site-verification" content="YOUR_TOKEN_HERE" />
   ```
3. Copy only the token inside `content="..."` (not the full tag).
4. Add it to `apps/generator-app/.env.local`:
   ```
   NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION=YOUR_TOKEN_HERE
   ```
5. Redeploy the site so the meta tag is live in production HTML.

## 3. DNS TXT verification

1. On the same GSC property setup, open the **Domain name provider** (DNS TXT) method.
2. Copy the TXT record value (looks like `google-site-verification=xxxxxxxx`).
3. At your DNS host, add a **TXT** record:
   - **Host / Name:** `@` (or leave blank for root domain)
   - **Type:** `TXT`
   - **Value:** `google-site-verification=xxxxxxxx` (paste the value from GSC)
4. Save the record and wait for DNS propagation (often minutes, sometimes up to 48 hours).

## 4. Verify in Search Console

1. After deploy (meta tag) and DNS propagation (TXT), return to GSC.
2. Click **Verify** for the HTML tag method.
3. Click **Verify** for the DNS TXT method.
4. Either method alone proves ownership; using both is fine.

## 5. Submit the sitemap

1. In GSC, open the `dailyclarity.org` property.
2. Go to **Sitemaps** in the left sidebar.
3. Enter `https://dailyclarity.org/sitemap.xml` and click **Submit**.

The sitemap is generated by Next.js at `/sitemap.xml` and lists all public marketing pages with absolute `https://dailyclarity.org` URLs.
