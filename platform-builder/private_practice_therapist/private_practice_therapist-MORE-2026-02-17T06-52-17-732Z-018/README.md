Contact page and how to use it\n\nFiles in this bundle chunk:\n- contact.html: The contact page with a Mood-to-Method selector, contact form (mailto-based), session boundaries and confidentiality accordions, and a crisis footer. Designed for a glass-morphism aesthetic and references a local SVG pattern at assets/img/pattern.svg.\n\nHow Mood-to-Method works\n- The select control labeled 'How are you right now?' maps five states to suggested ways of working: Intro Consultation, Short Check-in, Guided Series, Transition Support, and Ongoing Support.\n- When the user changes the selection the UI updates: the method title, a short description, and the primary CTA text. The primary CTA retains its original link ({{PRIMARY_CTA_URL}}) but appends a fragment to indicate the chosen mood.\n- The CTA label is generated as: [Suggested approach] — [{{PRIMARY_CTA_LABEL}}] so the user sees both the suggestion and the standard action phrase.\n\nForm behavior and privacy note\n- The contact form does not submit to a server. 'Send via email' constructs a mailto: link to {{EMAIL}} with the entered data. This keeps messages on the user’s device and avoids client-side submission to unknown endpoints.\n- The page includes clear notes about confidentiality, limits of confidentiality, and a respectful crisis footer advising callers to contact emergency services or local crisis lines when needed. No medical guarantees or promises are made.\n\nPlaceholders to provide during deployment\n- {{BUSINESS_NAME}}\n- {{TAGLINE}}\n- {{PHONE}}\n- {{EMAIL}}\n- {{PRIMARY_CTA_LABEL}}\n- {{PRIMARY_CTA_URL}}\n- {{CITY}}\n- {{STATE}}\n\nAccessibility and testing\n- The page uses semantic elements (details/summary, form inputs) and labels.\n- Test the mailto behavior on your device to ensure it opens the preferred mail client.\n- The page references assets/img/pattern.svg for the decorative background; include a unique SVG at that path in your project for the pattern to appear.\n\nNotes for clinicians and compliance\n- The copy intentionally avoids medical claims and contains a clear explanation of confidentiality limits and how to access crisis services.\n- If you need to adapt crisis contact details to your country or organization, edit the crisis copy in contact.html.\n\nCustomization tips\n- To change the mood options or mapping, edit the mapping object in the inline script in contact.html (the keys: curious, overwhelmed, stuck, transition, maintaining).\n- To change visual theming, modify CSS variables at the top of the style block.\n\nIf you need an additional file (for example assets/img/pattern.svg) included in this chunk, request the next chunk to add it.
