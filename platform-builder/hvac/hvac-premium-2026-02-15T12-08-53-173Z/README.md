HVAC Premium Website Template

Slug: hvac-premium-2026-02-15T12-08-53-173Z

Description
- A premium, responsive, accessible, multi-page static website template tailored for HVAC companies.
- Works fully offline. No external fonts, CDNs, or images.
- Uses system font stack and local SVG assets only.

Pages
- index.html (Home)
- services.html
- pricing.html
- financing.html
- about.html
- reviews.html
- book.html
- contact.html

Local Assets
- assets/css/styles.css
- assets/js/main.js
- assets/img/avatar-01.svg
- assets/img/hero-abstract.svg

How to Use
1) Replace placeholders: Perform a find/replace across the project for each {{PLACEHOLDER}}.
2) Open index.html locally in your browser to preview.
3) Customize styles in assets/css/styles.css if needed.
4) Add your own images if desired; keep them local to maintain the offline guarantee.

Accessibility & SEO
- Semantic HTML with landmark roles.
- Color-contrast friendly palette and focus states.
- Alt text on decorative images and meaningful icons.
- Meta tags for SEO and OpenGraph on every page.
- Schema.org JSON-LD for Organization and Reviews.

JavaScript Features (assets/js/main.js)
- Mobile navigation toggle with accessible aria-expanded state.
- Accordion component for FAQs/services.
- Basic reviews carousel controls.
- Financing monthly payment calculator.
- Client-side form validation helpers.

Notes
- Forms are static and do not submit anywhere by default. You can set action attributes to your backend endpoints or services if available.
- For the CTA button/link, set {{PRIMARY_CTA_URL}} and {{PRIMARY_CTA_LABEL}}. For example, set the URL to /book.html or your external booking link.
