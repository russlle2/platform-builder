HVAC Premium Template

Overview
- A modern, responsive, accessible, and SEO‑ready static website template for HVAC businesses.
- Works entirely offline. No external fonts, images, or CDNs.

Structure
- Pages: index.html, services.html, pricing.html, financing.html, about.html, reviews.html, book.html, contact.html
- Assets: assets/css/styles.css, assets/js/main.js, assets/img/avatar-01.svg, assets/img/hero-abstract.svg
- Config: template.json, fields.json

Brand Fields (placeholders)
- {{BUSINESS_NAME}}, {{TAGLINE}}, {{PHONE}}, {{EMAIL}}, {{ADDRESS}}, {{CITY}}, {{STATE}}, {{ZIP}}, {{HOURS}}, {{PRIMARY_CTA_URL}}, {{PRIMARY_CTA_LABEL}}

Getting Started
1) Clone the repository.
2) Open index.html in your browser to preview.
3) Replace placeholders with your business info or wire this template into your CMS/build tool to inject fields from fields.json.

Accessibility
- Semantic tags, labeled forms, visible focus states, skip link, and ARIA where appropriate.

SEO
- Each page includes meta description, canonical URL, Open Graph, and Twitter Card tags.
- Index includes LocalBusiness JSON‑LD schema.

Customization Tips
- Colors and spacing are defined with CSS variables in assets/css/styles.css.
- Use the system font stack for performance and a native look and feel.
- Swap the call‑to‑action URL/label via {{PRIMARY_CTA_URL}} and {{PRIMARY_CTA_LABEL}}.

Forms
- Forms are non‑functional by default (action="#"). Hook them to your backend or form service.
- Basic client‑side validation and enhancements in assets/js/main.js.
