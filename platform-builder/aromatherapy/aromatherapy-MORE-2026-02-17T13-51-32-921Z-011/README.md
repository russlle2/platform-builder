Contact page and local tools for the aromatherapy site\n\nFiles in this bundle (chunk 4):\n- contact.html — full contact page with interactive features:\n  - Quick contact form (client-side only, shows confirmation).\n  - Blends builder: select a vibe, bottle size, and dilution to generate a 3-oil suggestion, approximate drop counts, mixing notes, and local save to browser storage. Safety-forward language only; not medical advice.\n  - Guided exercise modal: an accessible, JS-driven micro-practice (breathing cycles with timers, short journaling prompt, intention setting).\n  - FAQ safety blurbs: dilution, patch test, pregnancy/children, pets.\n  - Navigation links to other site pages and placeholders for site variables: {{BUSINESS_NAME}}, {{TAGLINE}}, {{PHONE}}, {{EMAIL}}, {{PRIMARY_CTA_LABEL}}, {{PRIMARY_CTA_URL}}, {{CITY}}, {{STATE}}.\n\nHow to use locally:\n1. Drop contact.html into a static site folder alongside the other site pages (index.html, services.html, blends.html, shop.html, pricing.html, about.html, book.html).\n2. Ensure assets/img/pattern.svg exists if you plan to reference the site background pattern elsewhere. This particular chunk does not include that SVG.\n3. Open contact.html in a browser. The blends tool stores data in localStorage/sessionStorage; saved blends are browser-local and not transmitted.\n\nAccessibility & constraints:\n- No external assets, fonts, or CDNs are required.\n- All interactions run in local JS only.\n- All content is written to be safety-conscious; avoid medical language.\n\nIf you need an alternate tone, additional copy variants for the contact prompts, or a separate debug view for saved blends, tell me which you'd like and I will produce a revised chunk.\n
