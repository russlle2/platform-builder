Chunk 4 / contact + README

Files included in this bundle:
- contact.html — Contact page with two interactive tools: Session Planner and Blend Builder. Includes a small contact form, FAQ about dilution/patch testing/pregnancy/pets, and copy/export functionality.

How to use locally:
1. Save the included file (contact.html) into a folder.
2. Open contact.html in a modern browser (Chrome, Firefox, Edge, Safari).
3. Interact with the "Session Planner" to create a short plan and copy the plaintext summary.
4. Use the "Blend Builder" to pick a vibe and bottle size; it will output an approximate dilution guide and a blend card. You can copy the blend text or save it as a .txt file.

Notes / placeholders:
- The page includes template placeholders that should be replaced when deploying: {{BUSINESS_NAME}}, {{PHONE}}, {{EMAIL}}, {{PRIMARY_CTA_LABEL}}, {{PRIMARY_CTA_URL}}, {{CITY}}, {{STATE}}.
- Safety: The tools provide general aromatherapy guidance only. They are not medical instructions. The FAQ contains notes about patch testing, pregnancy, and pet safety. Always consult a qualified provider for specific medical concerns.

Development:
- No external assets or CDNs are required. The page is self-contained (HTML, CSS, JS) and works offline.
- The blend dilution math assumes ~20 drops per ml for calculation purposes and rounds to whole drops.
