Micro-habits to layer with scent

Tiny daily rituals that pair with aroma for approachable wellbeing. Start small — 1–5 minutes each day.

  • Morning mist: 3–4 spray room blend to set intention.
  • Roll-on pocket: 1–2 gentle swipes on wrists for commute calm.
  • Diffuser focus: 15–30 min during concentrated work sessions.
  • Evening inhale: 2–3 slow inhales from a handkerchief before bed.

Tip: Record responses in a scent journal — scent memory is personal. Reduce frequency if sensitivity develops.
