Contact page and usage notes\n\nThis chunk contains two files for the contact area of the sound bath site.\n\nFiles included:\n- contact.html — the full contact page, with interactive Proof Gallery (rotating testimonials + credibility badges with tooltips), a micro Pricing Comparator (Per Visit vs Pack) with animated numbers, and a contact form that uses a mailto-style fallback. It includes the required contraindications disclaimer.\n- README.md — this file.\n\nPlaceholders to replace in your integration environment (do not remove if you intend to programmatically replace values):\n- {{BUSINESS_NAME}}\n- {{TAGLINE}}\n- {{PHONE}}\n- {{EMAIL}}\n- {{PRIMARY_CTA_LABEL}}\n- {{PRIMARY_CTA_URL}}\n- {{CITY}}\n- {{STATE}}\n\nIntegration notes:\n- Navigation uses a different label set to meet uniqueness requirements: Gatherings, Calendar, Sessions, Investment, Story, Notes, Reserve, Connect — links point to the canonical pages in the project: index.html, events.html, private-sessions.html, pricing.html, about.html, faq.html, book.html, contact.html.\n- The Proof Gallery rotates testimonials every 5s, with prev/next controls and dots. Badges include hover tooltips for credibility text. All implemented in vanilla JS in contact.html.\n- Pricing Comparator toggles between two pricing moods (single vs pack) and animates numeric transitions using requestAnimationFrame for smooth easing. Buttons update ARIA pressed state.\n- Contact form does not post to a server. Instead it builds a mailto link and offers to open it; it also supports copying the message to clipboard. Replace or hook up to a backend as needed.\n\nAccessibility & safety:\n- Simple keyboard focus available on badges (tabindex) to reveal tooltips.\n- Contraindications block is present; update as required to comply with local guidance.\n\nStyling and assets:\n- No external assets or CDNs. The page uses local inline CSS and SVG shapes. If you maintain an assets/img/pattern.svg for site-wide decoration, you may reference it in other templates; this chunk intentionally keeps everything inline.\n\nCustomization tips:\n- Edit the testimonial objects in the script to change the proof content.\n- Adjust pricing values in the comparator block (values object) to change animations and offers.\n- Swap the contact form behavior with an XHR / fetch POST to integrate a server endpoint.\n\nDeveloper notes:\n- Keep placeholders intact for templating systems.\n- The contact.html is self-contained — drop it into your static site root with the other pages.\n\nIf you need a separate assets SVG or additional pages from this project, request the next chunk and I will provide them.
