# Dental Premium Template

Template slug: dental-premium-2026-02-15T17-26-22-794Z

A premium, accessible, multi-page static website template for a modern dental office. 100% offline-capable with only local assets. Built with semantic HTML, responsive CSS, and progressive enhancement.

Getting started
- Download or clone the repository.
- Open index.html in your browser. No build step required.
- Replace placeholder fields in all HTML files (e.g., {{BUSINESS_NAME}}, {{PHONE}}) or connect to your CMS to inject values.

File structure
- Root pages: index.html, services.html, insurance.html, new-patient.html, about.html, reviews.html, book.html, contact.html
- Assets: assets/css/styles.css, assets/js/main.js, assets/img/avatar-01.svg, assets/img/hero-abstract.svg
- Config: template.json, fields.json

Customization
- Colors, spacing, and typography are controlled via CSS variables at the top of assets/css/styles.css.
- System font stack only; no external fonts are used.
- Logos/imagery: Swap assets/img/avatar-01.svg and assets/img/hero-abstract.svg with your own while keeping the filenames (or update references accordingly).

Accessibility
- Includes a skip link, semantic landmarks, visible focus states, and ARIA live regions for form feedback.
- All interactive elements have appropriate labels.

SEO & Social
- Each page includes meta description, canonical URL, Open Graph, and Twitter cards.
- LocalBusiness (Dentist) JSON-LD appears on key pages.

Forms
- Forms are wired to a simple JS handler that simulates submission and displays a success message. Replace with your backend or service endpoint as needed.
