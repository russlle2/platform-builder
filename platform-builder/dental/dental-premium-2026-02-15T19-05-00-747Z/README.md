Template: Dental Office — Premium Static Website
Slug: dental-premium-2026-02-15T19-05-00-747Z

Overview
- Fully static, multi-page, responsive template for a modern dental practice.
- Works 100% offline. No external fonts, images, or CDNs.
- Accessible, SEO-ready, OpenGraph tags, and structured data included.

How to use
1) Clone or download the bundle.
2) Replace template placeholders in HTML with your real info (or use an automated replacer):
   - {{BUSINESS_NAME}}
   - {{TAGLINE}}
   - {{PHONE}}
   - {{EMAIL}}
   - {{ADDRESS}}
   - {{CITY}}
   - {{STATE}}
   - {{ZIP}}
   - {{HOURS}}
   - {{PRIMARY_CTA_URL}}
   - {{PRIMARY_CTA_LABEL}}
3) Open index.html in your browser. No build step required.

Global assets
- CSS: assets/css/styles.css
- JS:  assets/js/main.js
- Images: assets/img/avatar-01.svg, assets/img/hero-abstract.svg

Pages
- index.html (Home)
- services.html (Services Overview)
- insurance.html (Insurance & Membership)
- new-patient.html (New Patient Guide)
- about.html (About the Practice)
- reviews.html (Reviews & Ratings)
- book.html (Book Appointment)
- contact.html (Contact & Directions)

Accessibility
- Semantic HTML, labeled form controls, skip-to-content link, visible focus, high contrast.
- Reduced motion respected with prefers-reduced-motion.

SEO & Social
- Unique title and description per page.
- OpenGraph and Twitter Card tags using local assets.
- JSON-LD structured data (Dentist LocalBusiness) on each page.

Customization tips
- Colors and spacing via CSS variables in assets/css/styles.css.
- Navigation and UI behaviors in assets/js/main.js.
- Update template.json and fields.json for integration with your CMS or templating system.
